# STOCKPILOT AI — Firestore Architecture & Schema Documentation

## 1. Multi-Tenant Organization Scoping
Every document contains an `org_id` string field (`org_triwiz_01`). 
Firestore Security Rules enforce that clients can only read/query documents where `request.auth.token.org_id == resource.data.org_id`.

## 2. Collections Overview

### `organizations`
- `id` (string): Unique identifier (e.g. `org_triwiz_01`)
- `name` (string): Organization legal name
- `code` (string): Short identifier (e.g. `ABLG`)
- `industry` (string): e.g. "Pharmaceuticals & Cold-Chain Logistics"
- `status` (string): `"active" | "suspended"`
- `created_at` (timestamp / ISO string)

### `users`
- `id` (string): Unique user ID (or Firebase Auth UID)
- `email` (string)
- `full_name` (string)
- `role` (string): `"super_admin" | "org_admin" | "supply_chain_manager" | "warehouse_manager" | "distributor" | "operator"`
- `org_id` (string): Tenant reference
- `warehouse_id` (string | null): Assigned warehouse
- `phone_number` (string | null): WhatsApp identifier
- `is_active` (boolean)

### `warehouses`
- `id` (string): e.g. `wh_chicago_01`
- `org_id` (string)
- `code` (string): e.g. `WH-ORD-01`
- `name` (string): e.g. `Central Hub Chicago`
- `lat` (float), `lng` (float)
- `capacity_pallets` (integer)
- `used_pallets` (integer)
- `cold_storage_capacity` (integer)
- `is_operational` (boolean): Disruption toggle

### `products`
- `id` (string): e.g. `prd_vax_01`
- `org_id` (string)
- `sku` (string): Unique stock-keeping unit (e.g. `PRD-VAX-01`)
- `name` (string)
- `category` (string)
- `handling` (string): `"cold_chain" | "deep_freeze" | "ambient" | "hazardous" | "fragile"`
- `unit` (string): `"vials" | "pens" | "bottles" | "cartons"`
- `unit_cost` (float), `selling_price` (float)
- `min_safety_stock` (integer), `reorder_point` (integer)
- `barcode` (string)
- `qr_code_payload` (string): `STOCKPILOT://SKU/<SKU>/ORG/<ORG_ID>`
- `shelf_life_days` (integer)

### `inventory` (Aggregated by Warehouse & Product)
- `id` (string): `inv_{warehouse_id}_{product_id}`
- `org_id` (string)
- `warehouse_id` (string)
- `product_id` (string)
- `total_quantity` (integer)
- `reserved_quantity` (integer)
- `available_quantity` (integer)
- `damaged_quantity` (integer)
- `in_transit_quantity` (integer)
- `safety_stock` (integer)
- `reorder_point` (integer)

### `inventory_batches` (FEFO Expiry Tracking)
- `id` (string): `bat_{warehouse_id}_{batch_number}`
- `org_id` (string)
- `warehouse_id` (string)
- `product_id` (string)
- `batch_number` (string)
- `mfg_date` (string: YYYY-MM-DD)
- `expiry_date` (string: YYYY-MM-DD)
- `quantity` (integer)
- `reserved_quantity` (integer)
- `damaged_quantity` (integer)
- `unit_cost` (float)
- `storage_bin` (string)
- `status` (string): `"active" | "quarantined" | "expired" | "depleted"`

### `inventory_movements` (Immutable Append-Only Ledger)
- `id` (string): `mov_{uuid}`
- `org_id` (string)
- `correlation_id` (string): Idempotency key
- `product_id` (string)
- `batch_id` (string | null)
- `source_warehouse_id` (string | null)
- `destination_id` (string | null)
- `movement_type` (string): `"receipt" | "dispatch" | "transfer_out" | "transfer_in" | "adjustment" | "damage_report"`
- `quantity_changed` (integer)
- `balance_after` (integer)
- `actor_id` (string), `actor_name` (string)
- `reason` (string)
- `timestamp` (ISO string)

### `transfers` (Inter-Warehouse Transfers)
- `id` (string): `trf_{uuid}`
- `transfer_number` (string): e.g. `TRF-2026-0891`
- `source_warehouse_id` (string)
- `target_warehouse_id` (string)
- `items` (array of objects): `[{ product_id, batch_id, quantity, unit_cost }]`
- `status` (string): `"pending" | "approved" | "in_transit" | "received" | "rejected"`
- `requested_by_id` (string)
- `approved_by_id` (string | null)
- `estimated_transport_cost` (float)

### `iot_devices` & `sensor_readings`
- `iot_devices`: Mac address, IP, warehouse_id, storage_zone, thresholds (min_temp, max_temp, max_humidity).
- `sensor_readings`: Chronological telemetry. High-volume retention: rolling 30-day retention with 1-hour hourly summary rollups.

### `alerts`
- `id`, `alert_type`, `severity` (`"critical" | "warning"`), `message`, `reading_value`, `threshold_value`, `timestamp`, `acknowledged`, `acknowledged_by`.

### `optimization_runs`
- Generated by Google OR-Tools MIP solver: contains input parameters, baseline heuristic comparison, cost savings, fill rate %, and allocation recommendations.
